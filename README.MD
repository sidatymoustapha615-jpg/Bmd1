# BMD AI Trading Agent

وكيل ذكاء اصطناعي لمراقبة وتحليل العملات الرقمية على Binance.

## إعدادات المشروع
- السوق: العملات الرقمية
- المنصة: Binance
- نوع التداول: Spot
- التشغيل الأول: Paper Trading (تجريبي)
- رأس المال الافتراضي: 1000 USDT
- الإطار الزمني: 15 دقيقة
- الاستراتيجية: EMA 9 / EMA 21
- عدد العملات: 20

## المراحل
1. جلب بيانات السوق.
2. تحليل العملات وإصدار الإشارات.
3. تنفيذ صفقات افتراضية.
4. تسجيل النتائج وإدارة المخاطر.
5. اختبار النظام قبل التفكير في التداول الحقيقي.

تنبيه: التداول الحقيقي معطل في النسخة الأولى. لا توجد أرباح مضمونة.
